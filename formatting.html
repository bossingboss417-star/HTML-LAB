HTML Text Formatting

Explanation of Each Formatting Tag

Bold Text: The b tag makes text bold to draw attention without adding extra semantic importance.

HTML stands for HyperText Markup Language. The strong tag defines text with strong importance, while the em tag defines emphasized text.

Italic Text: The i tag displays text in italics, often used for technical terms or phrases.

Underlined Text: The u tag adds an underline to the text.

Marked Text: The mark tag highlights text for reference or notation purposes.

Small Text: The small tag makes the text size smaller, commonly used for side comments and copyright notices.

The del tag indicates deleted or removed text, while the ins tag indicates newly inserted text in a document.

The sub tag creates subscript text that sits below the normal line, and the sup tag creates superscript text that sits above the normal line.
